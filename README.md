# わたしの資産

iPhoneで使う、個人用のシンプルな投資管理Webアプリです。外部API・ログイン・サーバー側データベースを使わず、入力した資産をブラウザのlocalStorageに保存します。外部フォントや分析ツールも使いません。

## できること

- 現金：名前と残高を登録
- 個人向け国債：名前と保有額（額面）を登録
- オルカン：名前、取得総額、現在評価額を登録
- 日本株：銘柄名、株数、平均取得単価、現在価格を登録
- 総資産・4種類の資産配分・オルカンと日本株の含み損益を表示
- 資産の編集・確認付き削除、JSONバックアップの書き出し・復元
- HTTPSで一度読み込んだ後は、オフラインでも利用可能

現在価格は自分で入力します。日本株の評価額は「株数 × 現在価格」、取得額は「株数 × 平均取得単価」です。総資産は現金・国債額面・オルカン評価額・日本株評価額の合計です。損益率の分母はオルカンと日本株の取得総額の合計です。利息・配当・税金・売却済み資産の損益は計算に含みません。

## 開発環境で動かす

Node.js 18以上（テスト用）とPython 3があれば、追加パッケージのインストールは不要です。

```sh
cd /workspace/investment-dashboard
npm test
npm start
```

開発サーバーは8080番ポートで動きます。停止はCtrl+Cです。起動確認は `curl --fail http://127.0.0.1:8080/` で行えます。静的ファイルだけのため、ビルドは不要です。

## iPhoneで使い始める（GitHub Pages）

クラウド開発環境を起動しただけでは、iPhoneから利用できる公開サイトにはなりません。以下は無料のGitHub Pagesを使う方法です。公開操作は、このアプリのコードをGitHubに保存した後にご自身で行ってください。

1. このフォルダのファイルをGitHubの `nikochandaimaou/investment-dashboard` リポジトリの `main` ブランチに保存します。Webで行う場合は「Add file」→「Upload files」からアップロードし、「Commit changes」を押します。`tests` フォルダなどは不要で、公開に必要なのは `index.html`、`style.css`、`app.js`、`model.js`、`sw.js`、`manifest.webmanifest`、`icon.svg`、`apple-touch-icon.png` です。
2. リポジトリの「Settings」→「Pages」を開きます。
3. 「Build and deployment」のSourceで「Deploy from a branch」を選択します。
4. Branchを `main`、フォルダを `/ (root)` にして「Save」を押します。
5. 数分待って、Pages画面に表示される公開URLをコピーします。通常は `https://nikochandaimaou.github.io/investment-dashboard/` です（公開するまでは使えません）。
6. iPhoneのSafariでそのURLを開きます。
7. Safariの共有ボタン（四角から上向き矢印）→「ホーム画面に追加」→「追加」を押します。iOSによっては「Webアプリとして開く」をオンにします。
8. ホーム画面の「わたしの資産」を開き、「＋ 資産を追加」から登録します。

無料プランでは通常、公開リポジトリが必要です。非公開リポジトリのPages利用可否は契約プランによります。公開されるのはアプリのコードです。入力した資産データはGitHubに送信しません。ただし、ログインによる利用制限はなく、URLを知っている人は自分の端末で同じアプリを使えます。

## データ保存と機種変更

- 最初からホーム画面のアプリで登録するのがおすすめです。Safariとホーム画面のWebアプリで保存領域が異なることがあるため、同じデータが見えるとは限りません。
- 別端末・別ブラウザ・別URLへ自動同期しません。共有端末ではブラウザを利用できる人が資産データを閲覧できます。
- 「書き出す」を押し、JSONファイルをiPhoneの「ファイル」などに保存してください。資産額を含むので大切に保管してください。
- 機種変更時は、同じアプリで「読み込む」を押してバックアップファイルを選びます。確認後、現在のデータ全体を置き換えます。
- ブラウザの履歴・サイトデータの削除、プライベートブラウズ、OSによる保存領域の整理でデータが消える可能性があります。定期的にバックアップしてください。
- オフライン利用はHTTPSで初回読み込み・キャッシュ完了後に有効です。最初は通信できる状態で開いてください。

## 構成と更新

HTML/CSS/JavaScriptの静的アプリです。`model.js` に計算と入力・バックアップ検証、`app.js` に画面と保存処理、`sw.js` にオフラインキャッシュがあります。更新時は `sw.js` のキャッシュ名を新しいバージョンに変更すると旧キャッシュを整理できます。

## 金融機関・口座ごとの管理と既存データの更新

資産登録・編集で「金融機関」と「口座名」を入力します（例：SBI新生銀行／普通預金、SBI証券／NISA、SBI証券／特定口座）。既に使った名前は入力候補に表示されます。同じ金融機関は同じ表記で入力してください。

各資産には金融機関・口座の組を1つだけ保存します。金融機関合計と口座内訳は資産から自動計算し、総資産に足し直しません。口座を変更しても資産を複製しません。ただし、同じ資金を別の資産として手入力した場合は区別できません。証券口座全体の残高を現金として登録せず、現金には未投資の現金残高だけを登録してください。

以前のデータとJSONバックアップも読み込めます。保存キー・形式は維持し、金融機関のない資産は「口座未登録」に表示します。各資産の「編集」で金融機関と口座名を追加してください。更新のためにサイトデータを削除する必要はありません。

iPhoneで更新する前に「書き出す」でバックアップしてください。公開更新後、同じURL・同じブラウザまたはホーム画面アプリを通信できる状態で開き直します。新画面が出ない場合は一度閉じて再度開いてください。保存データはURLや利用環境に依存するため、URL変更やサイトデータ削除は避けてください。機種やブラウザの変更時はバックアップを読み込みます。
